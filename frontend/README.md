# PawSnap Frontend

This is the React + TypeScript + Vite frontend application for **PawSnap**, a pet breed classification app.

## Features

- **Interactive UI**: Clean, premium design for uploading and analyzing pet images.
- **Real-time Prediction**: Connects to the FastAPI backend to identify 37 dog and cat breeds.
- **Detailed Breed Info**: Displays fun facts, temperament, size, life expectancy, and grooming needs.

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion (for smooth transitions/animations)
- Lucide React (for icons)

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
